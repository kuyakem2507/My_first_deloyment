# Developer Profile - Single-Page Website

## Folder structure
```
developer-profile/
├── index.html          (page skeleton only)
├── css/
│   └── style.css       (external stylesheet)
├── js/
│   └── main.js         (external script: renders all content)
└── images/
    ├── profile.jpg     (add your photo, about 480 x 560 px)
    └── projects/       (add project screenshots: project1.png ... project4.png)
```

## How to customize
Open `js/main.js` and edit the `CONFIG` object at the top (name, motto, philosophy,
projects, GitHub links, contact). No HTML editing needed.
Missing images are replaced by an automatic placeholder.

## Resources
Bootstrap 5.3.3 (CSS + JS bundle) loaded from the jsDelivr CDN.
